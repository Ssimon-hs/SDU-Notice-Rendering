# 一键山大

本地优先的山东大学通知整理工作台。把散落在几十个官方站点的通知聚合起来，整理成可以理解、可以直接行动的信息，并保留跨学院内容，避免信息茧房。

> 非山东大学官方产品。所有关键信息请以官方原文为准。作者：松。

## 一键启动（推荐）

双击 **`启动一键山大.bat`**，浏览器会自动打开 `http://127.0.0.1:8765`。

停止：双击 **`停止一键山大.bat`**，或关闭名为 `YJSD-Server` 的黑色窗口。

首次打开会进入引导页，可以填写资料让推荐更准确，也可以直接「暂时跳过」。

## 手动启动

```bash
# 后端（同时托管前端构建产物，端口 8765）
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r server\requirements.txt
.venv\Scripts\python.exe -m uvicorn server.main:app --host 127.0.0.1 --port 8765

# 前端开发服务器（可选，端口 5173，自带 /api 代理）
npm install
npm run dev
```

## 功能概览

| 页面 | 说明 |
| --- | --- |
| 首次引导 | 左侧产品目的 / 由来 / 作者介绍，右侧 12 项资料填写，带进度、返回上一步、画像预览、暂时跳过 |
| 首页 | 大留白 + 大标语（时段问候 / 每日一句 / 自定义），右侧可折叠、可排序、可隐藏的功能栏 |
| 为你推荐 | 说明「为什么推荐给你」，支持不感兴趣、调整推荐范围，强制保留跨领域内容，不会自动加入待办 |
| 全部通知 | 14 项筛选条件，可保存自定义筛选，默认隐藏已截止，显示收录总数 |
| 搜索 | 覆盖标题、正文、附件、来源、适用对象、地点、材料名、历届；支持自然语言提问、错别字纠正 |
| 通知正文页 | 官方原标题、发布单位、时间、官方链接、AI 整理、材料、步骤、官方正文与附件、往年关联、错误反馈 |
| 我的待办 | 手动加入，状态流转、子任务、材料勾选、提醒、写入日历、历史恢复 |
| 收藏 | 文件夹、标签、备注、排序、搜索、批量操作、导出；不自动创建待办 |
| 校历 | 月视图 / 日程列表、颜色区分、点击打开通知、导出 .ics、切换「与我有关」 |
| 信息源管理 | 每个来源的抓取成功 / 失败、数量、最后更新时间、具体失败原因，支持添加自定义网站 |
| 校园社区 | 邮箱投稿模式：点击「投稿 / 征集」弹出作者「松」的个人邮箱，投稿内容经整理后展示 |
| 系统设置 | 三套主题（深色 / 浅色 / 山大红）、中英文、AI 配置、提醒设置、数据导入导出与重置 |

## 数据来源

- 内置核心来源：主站、本科生院、研究生院、就业中心、青岛校区、威海校区、团委、学生在线、本科招生、研究生招生、图书馆、信息化办、国际事务部等；
- 从山东大学官方「学院与研究院 / 管理服务机构 / 直属附属单位」目录自动发现 `*.sdu.edu.cn` 子站；
- 用户可自行添加网站；
- 每个来源自动发现栏目并翻页，读取正文与附件，默认只保留近三年内容；
- 抓取失败时如实报告原因（需要登录、证书异常、站点失效、栏目改版、解析失败），不会假装成功。

## 目录结构

```
server/            后端（FastAPI）
  main.py          路由（控制器）
  services.py      业务规则（筛选、搜索、关联、校历）
  classifier.py    分类、通知/新闻判定、适用对象、时间、材料抽取
  store.py         本地数据读写与备份
  migrate.py       旧数据迁移脚本
  sources/         抓取层（common / sdu_main / official_sites / discovery）
  tests/           pytest 用例
src/               前端（React + Vite）
  App.jsx          页面路由与全局状态
  lib/             api / store / i18n / recommend / utils
  components/      NoticeCard / Rail / Shared
  pages/           各页面
smoke/             前端渲染冒烟测试（node smoke/run.mjs）
data/              本地数据（notices.json、source_status.json、备份）
```

## 测试

```bash
# 后端
.venv\Scripts\python.exe -m pytest server/tests -q

# 前端渲染冒烟（无需浏览器）
npm run smoke
```
